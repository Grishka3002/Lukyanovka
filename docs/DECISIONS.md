# Решения — 2026-11-10

- Основа — существующий многостраничный сайт Railway, а не предыдущие отвергнутые макеты.
- Сохранены палитра, основные фотографии, маршруты страниц и административный контент. Новые визуализации не создавались.
- Мобильное меню: непрозрачная подложка на высоту экрана; у мобильного header убран backdrop-filter, создававший containing block для fixed-меню. Закрытые ссылки inert/visibility:hidden. Escape и удержание фокуса внутри открытой навигации.
- Hero: устранено сложение left:28px и margin-left:24px, вызывавшее обрезку. Убрана повторная полоса фактов, сокращены тексты, уменьшены внутренние заголовки.
- Комнаты: общий обзор и раскрываемый список, без выдуманных различий. Добавлены необязательные поля image/imageAlt в админке и их отображение, когда фотографии будут загружены.
- Форма: имя и комната необязательны; пожелания раскрываются отдельно; текущий выбор комнаты переносится из URL. Backend принимает эти данные с проверкой дат по времени Владивостока, согласия, контакта и длины полей.
- Доставка заявки: при delivered:false и ошибке данные не сбрасываются, интерфейс предлагает связаться напрямую. Реальные сообщения при тестировании не отправляются.
- Контент сразу отрисовывается из собранного content-defaults.js; /api/content обновляет его при отличии. Убрано скрытие секций до анимации и автопереключение отзывов.
