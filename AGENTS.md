# Маори — опубликованный сайт Railway

Начни с README.md и docs/STATE.md, docs/BRIEF.md, docs/DECISIONS.md.

Источник правды этого репозитория: index.html, rooms.html, host.html, location.html, booking.html, styles.css, script.js, server.js и data/content.json. Старый макет dist/ из соседнего проекта отвергнут пользователем и не является исходником этого сайта.

Сохраняй тёплую стилистику существующего сайта. Не придумывай портрет хозяйки, фотографии комнат, цены, отзывы, наличие мест и условия. Поля фото комнат добавлены в admin.js. content-defaults.js обновляется через npm run build.

Перед загрузкой: npm run build, npm test, node --check script.js, node --check server.js, node --check admin.js. Проверяй main перед обновлением ветки, не используй force push. Не отправляй реальные заявки и сообщения для проверки. Честно сохраняй ограничения в docs/VERIFICATION.md.
